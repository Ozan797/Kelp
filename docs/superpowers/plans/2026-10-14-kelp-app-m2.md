# Kelp app M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build milestone M2 of the Kelp Mac app: saved connections (validated before saving, secrets in the Keychain), browsing buckets and folders, single-file upload and download with progress, new folder and delete, in the approved three-pane window.

**Architecture:** Rust core in `app/src-tauri/src/`: `StorageProvider` grows the M2 operations; `profiles`, `secrets` and `validation` are plain testable modules; Tauri commands in `commands/` wire them to the UI through shared `AppState`. React UI in `app/src/`: typed wrappers in `lib/tauri.ts`, three small hooks for state, one component per piece of the window, styled with the shared design tokens.

**Tech Stack:** Rust 1.90 (edition 2024), Tauri 2.12, aws-sdk-s3 1.122, keyring 3.6, tokio 1, uuid 1; React 19, TypeScript 6, Vite 8, @tanstack/react-virtual 3, Vitest 5 + Testing Library 16 + jsdom; Tauri plugins dialog 2.8 and opener 2.7.

**Spec:** `docs/superpowers/specs/2026-10-14-kelp-app-m2-design.md` (read with `SPEC.md` sections 5.3–5.8 and `CLAUDE.md`).

## Global Constraints

- **Commits:** commit at the end of every task with the message given in its last step. Commit messages must **not** contain `Co-Authored-By` or any other attribution line. Never `git push` or `git merge` without asking the user.
- No code comments of any kind (no `//`, `///`, `//!`, `/* */`, JSX comments) in new or changed code (CLAUDE.md).
- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test` must pass at every checkpoint (`--manifest-path app/src-tauri/Cargo.toml`).
- No `unwrap()`/`expect()` outside tests in Rust. No `any` in TypeScript.
- Secret access keys live only in the macOS Keychain. Never in JSON, logs, error messages, events or test fixtures.
- UI never calls `invoke`/`listen` outside `app/src/lib/tauri.ts`.
- All colours from semantic tokens (`design/tokens.css`); no raw hex in `app/src`.
- Copy: sentence case, buttons say exactly what they do, errors say what happened and what to try, never apologise.
- Deleting objects always asks for confirmation first.
- Capabilities: add only `dialog:allow-open`, `dialog:allow-ask` (native confirmations), `opener:allow-reveal-item-in-dir`, `opener:allow-open-url` scoped to `https://kelp.ozanai.dev/*`, `core:menu:default`, and `core:window:allow-start-dragging` (the window is dragged by the rail and toolbar because the title bar is an overlay).
- M2 transfers are single requests; files over 5 GB fail with `AppError::FileTooLarge`.
- Rust crate pins (resolver keeps within Rust 1.90): `keyring = { version = "3", features = ["apple-native"] }`, `tauri-plugin-dialog = "2"`, `tauri-plugin-opener = "2"`.

## Review Focus

1. **Keychain save succeeds but `connections.json` write fails** (disk full, permissions) → the secret must be removed again so no orphan secret is left; the user sees the error and nothing is saved. Tested in Task 6.
2. **Downloading a file whose name already exists in `~/Downloads`** → never overwrite; save as `name (1).ext`, `name (2).ext`. Tested in Task 8 (`unique_download_path`).
3. **A key limited to one bucket** (ListBuckets denied) → the sheet asks for a bucket name, and the bucket column shows only that bucket without calling ListBuckets again. Tested in Tasks 5 and 7.
4. **Folder names typed into "New folder"** containing `/`, leading/trailing spaces, or empty → rejected with a plain message, never creating `a/b/` nested keys by accident. Tested in Task 7 (`folder_key`).
5. **Filtering and selection while more pages are still loading** → selected keys stay selected as new rows arrive; filter applies to newly loaded rows. Tested in Task 13 (FileList).

    pub fn load(&self) -> Result<Vec<ConnectionProfile>, AppError> {
        match std::fs::read_to_string(&self.path) {
            Ok(text) => serde_json::from_str(&text)
                .map_err(|error| AppError::Io(format!("connections.json is damaged ({error})"))),

            Err(error) => Err(error.into()),

    pub fn save(&self, profiles: &[ConnectionProfile]) -> Result<(), AppError> {
        if let Some(dir) = self.path.parent() {
            std::fs::create_dir_all(dir)?;
        }
        let json = serde_json::to_vec_pretty(profiles).map_err(|error| AppError::Io(error.to_string()))?;
        let temporary = self.path.with_extension("json.tmp");
        std::fs::write(&temporary, json)?;
        std::fs::rename(&temporary, &self.path)?;
        Ok(())
    }

fn keychain_error(error: impl std::fmt::Display) -> AppError {
    AppError::Keychain(error.to_string())
}

impl KeychainStore {
    fn entry(id: &Uuid) -> Result<keyring::Entry, AppError> {
        keyring::Entry::new(SERVICE, &id.to_string()).map_err(keychain_error)
    }
}

impl SecretStore for KeychainStore {
    fn get(&self, id: &Uuid) -> Result<String, AppError> {
        Self::entry(id)?.get_password().map_err(keychain_error)
    }

    fn set(&self, id: &Uuid, secret: &str) -> Result<(), AppError> {
        Self::entry(id)?.set_password(secret).map_err(keychain_error)
    }

    fn delete(&self, id: &Uuid) -> Result<(), AppError> {
        match Self::entry(id)?.delete_credential() {
            Ok(()) | Err(keyring::Error::NoEntry) => Ok(()),
            Err(error) => Err(keychain_error(error)),
        }
    }
}

impl MemoryStore {
    fn secrets(&self) -> Result<std::sync::MutexGuard<'_, HashMap<Uuid, String>>, AppError> {
        self.secrets.lock().map_err(|_| keychain_error("the secret store is unavailable"))
    }
}

impl SecretStore for MemoryStore {
    fn get(&self, id: &Uuid) -> Result<String, AppError> {
        self.secrets()?
            .get(id)
            .cloned()
            .ok_or_else(|| keychain_error("no secret is saved for this connection"))
    }

    fn set(&self, id: &Uuid, secret: &str) -> Result<(), AppError> {
        self.secrets()?.insert(*id, secret.to_string());
        Ok(())
    }

    fn delete(&self, id: &Uuid) -> Result<(), AppError> {
        self.secrets()?.remove(id);
        Ok(())
    }
}

impl Body for ProgressBody {
    type Data = Bytes;
    type Error = <SdkBody as Body>::Error;

    fn poll_frame(
        self: Pin<&mut Self>,
        cx: &mut Context<'_>,
    ) -> Poll<Option<Result<Frame<Self::Data>, Self::Error>>> {
        let this = self.get_mut();
        let polled = Pin::new(&mut this.inner).poll_frame(cx);
        if let Poll::Ready(Some(Ok(frame))) = &polled
            && let Some(data) = frame.data_ref()
        {
            this.sent += data.len() as u64;
            (this.report)(this.sent);
        }
        polled
    }

    fn is_end_stream(&self) -> bool {
        self.inner.is_end_stream()
    }

    fn size_hint(&self) -> SizeHint {
        Body::size_hint(&self.inner)
    }
}

    async fn delete(&self, bucket: &str, keys: &[String]) -> Result<(), AppError> {
        for batch in keys.chunks(1000) {
            let objects = batch
                .iter()
                .map(|key| ObjectIdentifier::builder().key(key).build())
                .collect::<Result<Vec<_>, _>>()
                .map_err(|error| AppError::Provider(error.to_string()))?;
            let delete = Delete::builder()
                .set_objects(Some(objects))
                .quiet(true)
                .build()
                .map_err(|error| AppError::Provider(error.to_string()))?;
            let output = self
                .client
                .delete_objects()
                .bucket(bucket)
                .delete(delete)
                .send()
                .await
                .map_err(|error| classify(error, bucket))?;
            if let Some(failed) = output.errors().first() {
                return Err(AppError::Provider(
                    failed.message().unwrap_or("Some files couldn't be deleted.").to_string(),
                ));
            }
        }
        Ok(())
    }

    async fn create_folder(&self, bucket: &str, prefix: &str) -> Result<(), AppError> {
        self.client
            .put_object()
            .bucket(bucket)
            .key(prefix)
            .body(ByteStream::from_static(b""))
            .send()
            .await
            .map_err(|error| classify(error, bucket))?;
        Ok(())
    }

    async fn put_file(&self, bucket: &str, key: &str, path: &Path, progress: ProgressFn) -> Result<(), AppError> {
        let size = tokio::fs::metadata(path).await?.len();
        if size > MAX_SINGLE_UPLOAD {
            return Err(AppError::FileTooLarge);
        }
        let file = ByteStream::from_path(path).await.map_err(|error| AppError::Io(error.to_string()))?;
        let body = ByteStream::new(SdkBody::from_body_1_x(ProgressBody::new(file.into_inner(), progress)));
        self.client
            .put_object()
            .bucket(bucket)
            .key(key)
            .content_length(i64::try_from(size).map_err(|_| AppError::FileTooLarge)?)
            .body(body)
            .send()
            .await
            .map_err(|error| classify(error, bucket))?;
        Ok(())
    }

    async fn get_file(&self, bucket: &str, key: &str, path: &Path, progress: ProgressFn) -> Result<(), AppError> {
        let mut output = self
            .client
            .get_object()
            .bucket(bucket)
            .key(key)
            .send()
            .await
            .map_err(|error| classify(error, bucket))?;
        let mut file = tokio::fs::File::create(path).await?;
        let mut received = 0u64;
        while let Some(chunk) = output.body.try_next().await.map_err(|_| AppError::Network)? {
            file.write_all(&chunk).await?;
            received += chunk.len() as u64;
            progress(received);
        }
        file.flush().await?;
        Ok(())
    }

use std::collections::HashMap;
use std::sync::Arc;

use tokio::sync::Mutex;
use uuid::Uuid;

use crate::connection::ConnectionSettings;
use crate::error::AppError;
use crate::profiles::{ConnectionProfile, ProfileStore};
use crate::providers::StorageProvider;
use crate::providers::s3::S3Provider;
use crate::secrets::SecretStore;

pub type Connect =
    Box<dyn Fn(&ConnectionSettings, &str) -> Result<Arc<dyn StorageProvider>, AppError> + Send + Sync>;

pub struct AppState {
    pub store: ProfileStore,
    pub secrets: Box<dyn SecretStore>,
    pub connect: Connect,
    pub profiles: Mutex<Vec<ConnectionProfile>>,
    providers: Mutex<HashMap<Uuid, Arc<dyn StorageProvider>>>,
}

pub fn real_connect() -> Connect {
    Box::new(|settings, secret| Ok(Arc::new(S3Provider::new(settings, secret)?)))
}

impl AppState {
    pub fn new(store: ProfileStore, secrets: Box<dyn SecretStore>, connect: Connect) -> Result<Self, AppError> {
        let profiles = store.load()?;
        Ok(Self {
            store,
            secrets,
            connect,
            profiles: Mutex::new(profiles),
            providers: Mutex::new(HashMap::new()),
        })
    }

    pub async fn profile(&self, id: Uuid) -> Result<ConnectionProfile, AppError> {
        self.profiles
            .lock()
            .await
            .iter()
            .find(|profile| profile.id == id)
            .cloned()
            .ok_or(AppError::ConnectionNotFound)
    }

    pub async fn provider(&self, id: Uuid) -> Result<Arc<dyn StorageProvider>, AppError> {
        if let Some(provider) = self.providers.lock().await.get(&id) {
            return Ok(provider.clone());
        }
        let profile = self.profile(id).await?;
        let secret = self.secrets.get(&id)?;
        let provider = (self.connect)(&profile.settings, &secret)?;
        self.providers.lock().await.insert(id, provider.clone());
        Ok(provider)
    }

    pub async fn forget_provider(&self, id: Uuid) {
        self.providers.lock().await.remove(&id);
    }
}
```

fn required(value: &str, message: &str) -> Result<String, AppError> {
    let trimmed = value.trim();
    if trimmed.is_empty() {
        return Err(AppError::InvalidSettings(message.into()));
    }
    Ok(trimmed.to_string())
}

fn secret_for(state: &AppState, draft: &ConnectionDraft) -> Result<String, AppError> {
    match (draft.secret.as_deref().map(str::trim).filter(|s| !s.is_empty()), draft.id) {
        (Some(secret), _) => Ok(secret.to_string()),
        (None, Some(id)) => state.secrets.get(&id),
        (None, None) => Err(AppError::InvalidSettings("Enter the secret key.".into())),
    }
}

pub async fn list(state: &AppState) -> Vec<ConnectionProfile> {
    state.profiles.lock().await.clone()

pub async fn test(state: &AppState, draft: &ConnectionDraft) -> Result<CheckResult, AppError> {
    required(&draft.settings.access_key_id, "Enter the access key.")?;
    let secret = secret_for(state, draft)?;
    let provider = (state.connect)(&draft.settings, &secret)?;
    check_connection(provider.as_ref(), draft.bucket.as_deref()).await
}

pub async fn save(state: &AppState, draft: ConnectionDraft) -> Result<ConnectionProfile, AppError> {
    let name = required(&draft.name, "Enter a name for this connection.")?;
    let check = test(state, &draft).await?;
    let secret = secret_for(state, &draft)?;
    let id = draft.id.unwrap_or_else(Uuid::new_v4);

    let mut profiles = state.profiles.lock().await;
    let last_location = profiles.iter().find(|p| p.id == id).and_then(|p| p.last_location.clone());
    let profile = ConnectionProfile {
        id,
        name,
        settings: draft.settings,
        bucket: if check.limited_to_bucket { check.buckets.first().cloned() } else { None },
        last_location,
    };

    let previous_secret = state.secrets.get(&id).ok();
    state.secrets.set(&id, &secret)?;

    let mut next: Vec<ConnectionProfile> = profiles.iter().filter(|p| p.id != id).cloned().collect();
    let position = profiles.iter().position(|p| p.id == id).unwrap_or(next.len());
    next.insert(position, profile.clone());

    if let Err(error) = state.store.save(&next) {
        let rollback = match previous_secret {
            Some(previous) => state.secrets.set(&id, &previous),
            None => state.secrets.delete(&id),
        };
        drop(rollback);
        return Err(error);
    }
    *profiles = next;
    drop(profiles);
    state.forget_provider(id).await;
    Ok(profile)
}

pub async fn delete(state: &AppState, id: Uuid) -> Result<(), AppError> {
    let mut profiles = state.profiles.lock().await;
    let next: Vec<ConnectionProfile> = profiles.iter().filter(|p| p.id != id).cloned().collect();
    state.store.save(&next)?;
    *profiles = next;
    drop(profiles);
    state.secrets.delete(&id)?;
    state.forget_provider(id).await;
    Ok(())
}

pub async fn set_last_location(state: &AppState, id: Uuid, location: Option<Location>) -> Result<(), AppError> {
    let mut profiles = state.profiles.lock().await;
    let mut next = profiles.clone();
    let profile = next.iter_mut().find(|p| p.id == id).ok_or(AppError::ConnectionNotFound)?;
    profile.last_location = location;
    state.store.save(&next)?;
    *profiles = next;
    Ok(())
}

pub fn folder_key(prefix: &str, name: &str) -> Result<String, AppError> {
    let name = name.trim();
    if name.is_empty() {
        return Err(AppError::InvalidSettings("Enter a name for the folder.".into()));
    }
    if name.contains('/') {
        return Err(AppError::InvalidSettings("Folder names can't contain a slash (/).".into()));
    }
    Ok(format!("{prefix}{name}/"))
}

pub async fn buckets(state: &AppState, id: Uuid) -> Result<Vec<String>, AppError> {
    if let Some(bucket) = state.profile(id).await?.bucket {
        return Ok(vec![bucket]);
    }
    state.provider(id).await?.list_buckets().await
}

pub async fn delete_objects(state: &AppState, id: Uuid, bucket: &str, keys: Vec<String>) -> Result<u64, AppError> {
    let provider = state.provider(id).await?;
    let mut targets = Vec::new();
    for key in keys {
        if key.ends_with('/') {
            let mut token = None;
            loop {
                let page = provider.list_keys(bucket, &key, token).await?;
                targets.extend(page.keys);
                token = page.next_token;
                if token.is_none() {
                    break;
                }
            }
            if !targets.contains(&key) {
                targets.push(key);
            }
        } else {
            targets.push(key);
        }
    }
    targets.sort();
    targets.dedup();
    provider.delete(bucket, &targets).await?;
    Ok(targets.len() as u64)
}

#[tauri::command]
pub async fn list_buckets(state: State<'_, AppState>, id: Uuid) -> Result<Vec<String>, AppError> {

    pub fn new(every: Duration) -> Self {
        Self { every, last: None }
    }

    pub fn ready(&mut self, now: Instant, finished: bool) -> bool {
        let due = self.last.is_none_or(|last| now.duration_since(last) >= self.every);
        if finished || due {
            self.last = Some(now);
            return true;
        }
        false
    }

pub fn safe_file_name(key: &str) -> String {
    match key.rsplit('/').next() {
        Some(name) if !name.is_empty() && name != "." && name != ".." => name.to_string(),
        _ => "download".to_string(),
    }
}

fn is_taken(path: &Path) -> bool {
    let mut part = path.as_os_str().to_owned();
    part.push(".part");
    path.exists() || Path::new(&part).exists()
}

pub fn unique_download_path(dir: &Path, name: &str) -> PathBuf {
    let first = dir.join(name);
    if !is_taken(&first) {
        return first;
    }
    let path = Path::new(name);
    let stem = path.file_stem().and_then(|stem| stem.to_str()).unwrap_or(name);
    let extension = path.extension().and_then(|ext| ext.to_str());
    (1..)
        .map(|n| match extension {
            Some(ext) => dir.join(format!("{stem} ({n}).{ext}")),
            None => dir.join(format!("{stem} ({n})")),
        })
        .find(|candidate| !is_taken(candidate))
        .unwrap_or(first)
}

#[derive(Default)]

}

impl Transfers {
    fn add(&self, id: Uuid, running: Running) {
        if let Ok(mut map) = self.running.lock() {
            map.insert(id, running);
        }
    }

    fn take(&self, id: Uuid) -> Option<Running> {
        self.running.lock().ok().and_then(|mut map| map.remove(&id))
    }
}

fn emit_state(app: &AppHandle, event: TransferStateEvent) {
    app.emit("transfer://state", event).ok();
}

fn state_event(id: Uuid, state: TransferStatus) -> TransferStateEvent {
    TransferStateEvent { id, state, info: None, error: None, path: None }
}

fn progress_reporter(app: AppHandle, id: Uuid, total: u64) -> ProgressFn {
    let throttle = Mutex::new(Throttle::new(Duration::from_millis(100)));
    Arc::new(move |done| {
        let ready = throttle.lock().map(|mut t| t.ready(Instant::now(), done >= total)).unwrap_or(true);
        if ready {
            app.emit("transfer://progress", TransferProgress { id, done, total }).ok();
        }
    })
}

fn finish(app: &AppHandle, id: Uuid, outcome: Result<Option<PathBuf>, AppError>) {
    app.state::<Transfers>().take(id);
    let event = match outcome {
        Ok(path) => TransferStateEvent {
            path: path.map(|p| p.to_string_lossy().into_owned()),
            ..state_event(id, TransferStatus::Finished)
        },
        Err(error) => TransferStateEvent { error: Some(error), ..state_event(id, TransferStatus::Failed) },
    };
    emit_state(app, event);
}

#[tauri::command(rename_all = "camelCase")]
pub async fn start_upload(
    app: AppHandle,
    state: State<'_, AppState>,
    id: Uuid,
    bucket: String,
    prefix: String,
    path: String,
    replace: bool,
) -> Result<Uuid, AppError> {
    let provider = state.provider(id).await?;
    let path = PathBuf::from(path);
    let name = path
        .file_name()
        .and_then(|name| name.to_str())
        .ok_or_else(|| AppError::Io("That file has no name.".into()))?
        .to_string();
    let total = tokio::fs::metadata(&path).await?.len();
    if total > MAX_SINGLE_UPLOAD {
        return Err(AppError::FileTooLarge);
    }
    let key = format!("{prefix}{name}");
    if !replace && provider.list_keys(&bucket, &key, None).await?.keys.first() == Some(&key) {
        return Err(AppError::AlreadyExists(name));
    }

    let transfer = Uuid::new_v4();
    let info = TransferInfo {
        id: transfer,
        direction: Direction::Upload,
        name,
        destination: format!("{bucket}/{prefix}"),
        total,
    };
    emit_state(&app, TransferStateEvent { info: Some(info), ..state_event(transfer, TransferStatus::Running) });

    let progress = progress_reporter(app.clone(), transfer, total);
    let task_app = app.clone();
    let task = tauri::async_runtime::spawn(async move {
        let outcome = provider.put_file(&bucket, &key, &path, progress).await.map(|()| None);
        finish(&task_app, transfer, outcome);
    });
    app.state::<Transfers>().add(transfer, Running { task, partial: None });
    Ok(transfer)
}

pub async fn start_download(
    app: AppHandle,
    state: State<'_, AppState>,
    id: Uuid,
    bucket: String,
    key: String,
    size: u64,
) -> Result<Uuid, AppError> {
    let provider = state.provider(id).await?;
    let dir = app.path().download_dir().map_err(|error| AppError::Io(error.to_string()))?;
    let name = safe_file_name(&key);
    let target = unique_download_path(&dir, &name);
    let mut partial = target.clone().into_os_string();
    partial.push(".part");
    let partial = PathBuf::from(partial);

    let transfer = Uuid::new_v4();
    let info = TransferInfo {
        id: transfer,
        direction: Direction::Download,
        name,
        destination: target.to_string_lossy().into_owned(),
        total: size,
    };
    emit_state(&app, TransferStateEvent { info: Some(info), ..state_event(transfer, TransferStatus::Running) });

    let progress = progress_reporter(app.clone(), transfer, size);
    let task_app = app.clone();
    let task_partial = partial.clone();
    let task = tauri::async_runtime::spawn(async move {
        let outcome = match provider.get_file(&bucket, &key, &task_partial, progress).await {
            Ok(()) => std::fs::rename(&task_partial, &target).map(|()| Some(target)).map_err(AppError::from),
            Err(error) => Err(error),
        };
        if outcome.is_err() {
            std::fs::remove_file(&task_partial).ok();
        }
        finish(&task_app, transfer, outcome);
    });
    app.state::<Transfers>().add(transfer, Running { task, partial: Some(partial) });
    Ok(transfer)
}

            std::fs::remove_file(partial).ok();
        }
        emit_state(&app, state_event(transfer, TransferStatus::Cancelled));
    }
    Ok(())
}

const UNITS = ["KB", "MB", "GB", "TB"];

export function formatBytes(bytes: number): string {
  if (bytes < 1000) return `${bytes} B`;
  let value = bytes;
  let unit = -1;
  while (value >= 1000 && unit < UNITS.length - 1) {
    value /= 1000;
    unit += 1;
  }
  const rounded = value < 10 ? Math.round(value * 10) / 10 : Math.round(value);
  return `${rounded} ${UNITS[unit]}`;
}

function sameDay(a: Date, b: Date): boolean {
  return a.getFullYear() === b.getFullYear() && a.getMonth() === b.getMonth() && a.getDate() === b.getDate();
}

export function formatModified(iso: string | null, now: Date = new Date()): string {
  if (!iso) return "—";
  const date = new Date(iso);
  if (sameDay(date, now)) {
    return `Today ${date.toLocaleTimeString("en-GB", { hour: "2-digit", minute: "2-digit" })}`;
  }
  const yesterday = new Date(now.getFullYear(), now.getMonth(), now.getDate() - 1);
  if (sameDay(date, yesterday)) return "Yesterday";
  const dayMonth = date.toLocaleDateString("en-GB", { day: "numeric", month: "short" });
  return date.getFullYear() === now.getFullYear() ? dayMonth : `${dayMonth} ${date.getFullYear()}`;
}

export function displayName(key: string, prefix: string): string {
  const rest = key.startsWith(prefix) ? key.slice(prefix.length) : key;
  return rest.endsWith("/") ? rest.slice(0, -1) : rest;
}

const EXTENSIONS: Record<string, FileKind> = {
  mp4: "video", mov: "video", mkv: "video", webm: "video", avi: "video", m4v: "video",
  jpg: "image", jpeg: "image", png: "image", gif: "image", webp: "image", svg: "image", heic: "image", avif: "image",
  txt: "text", md: "text", json: "text", csv: "text", log: "text", yml: "text", yaml: "text", xml: "text", html: "text",
};

export function fileKind(name: string, isFolder: boolean): FileKind {
  if (isFolder) return "folder";
  const dot = name.lastIndexOf(".");
  if (dot <= 0) return "other";
  return EXTENSIONS[name.slice(dot + 1).toLowerCase()] ?? "other";

export function toAppError(value: unknown): AppError {
  if (typeof value === "object" && value !== null && "kind" in value && "message" in value) {
    return value as AppError;
  }
  return { kind: "provider", message: String(value) };
}

async function call<T>(command: string, args?: Record<string, unknown>): Promise<T> {
  try {
    return await invoke<T>(command, args);
  } catch (error) {
    throw toAppError(error);

}

import { useCallback, useEffect, useRef, useState } from "react";
import { displayName } from "../lib/format";
import { api, toAppError, type AppError, type ListPage } from "../lib/tauri";

export type Row = { key: string; name: string; isFolder: boolean; size: number | null; lastModified: string | null };

export function pageToRows(page: ListPage, prefix: string): Row[] {
  const folders = page.folders.map((key) => ({
    key,
    name: displayName(key, prefix),
    isFolder: true,
    size: null,
    lastModified: null,
  }));
  const files = page.objects.map((object) => ({
    key: object.key,
    name: displayName(object.key, prefix),
    isFolder: false,
    size: object.size,
    lastModified: object.lastModified,
  }));
  return [...folders, ...files];
}

export function useListing(connectionId: string | null, bucket: string | null, prefix: string) {
  const [rows, setRows] = useState<Row[]>([]);
  const [token, setToken] = useState<string | null>(null);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<AppError | null>(null);
  const request = useRef(0);

  const fetchPage = useCallback(
    async (pageToken: string | null, replace: boolean) => {
      if (!connectionId || !bucket) return;
      const ticket = ++request.current;
      setLoading(true);
      setError(null);
      try {
        const page = await api.listObjects(connectionId, bucket, prefix, pageToken);
        if (ticket !== request.current) return;
        setRows((current) => (replace ? pageToRows(page, prefix) : [...current, ...pageToRows(page, prefix)]));
        setToken(page.nextToken);
      } catch (caught) {
        if (ticket === request.current) setError(toAppError(caught));
      } finally {
        if (ticket === request.current) setLoading(false);
      }
    },
    [connectionId, bucket, prefix],
  );

  useEffect(() => {
    setRows([]);
    setToken(null);
    fetchPage(null, true);
  }, [fetchPage]);

  const loadMore = useCallback(() => {
    if (token && !loading) fetchPage(token, false);
  }, [token, loading, fetchPage]);

  const reload = useCallback(() => fetchPage(null, true), [fetchPage]);

  return { rows, loading, error, hasMore: token !== null, loadMore, reload };
}

import { useCallback, useEffect, useReducer } from "react";
import {
  api,
  type AppError,
  type TransferInfo,
  type TransferProgress,
  type TransferStateEvent,
  type TransferStatus,
} from "../lib/tauri";

export type Transfer = TransferInfo & { status: TransferStatus; done: number; error: AppError | null; path: string | null };

export type TransferAction =
  | { type: "state"; event: TransferStateEvent }
  | { type: "progress"; event: TransferProgress }
  | { type: "clearFinished" };

export function transfersReducer(state: Transfer[], action: TransferAction): Transfer[] {
  switch (action.type) {
    case "state": {
      const { event } = action;
      if (event.info) {
        return [...state, { ...event.info, status: event.state, done: 0, error: null, path: null }];
      }
      return state.map((t) =>
        t.id === event.id ? { ...t, status: event.state, error: event.error, path: event.path, done: event.state === "finished" ? t.total : t.done } : t,
      );
    }
    case "progress":
      return state.map((t) => (t.id === action.event.id ? { ...t, done: action.event.done } : t));
    case "clearFinished":
      return state.filter((t) => t.status === "running" || t.status === "failed");
  }
}

export function useTransfers() {
  const [transfers, dispatch] = useReducer(transfersReducer, []);

  useEffect(() => {
    const stops = [
      api.onTransferState((event) => dispatch({ type: "state", event })),
      api.onTransferProgress((event) => dispatch({ type: "progress", event })),
    ];
    return () => {
      stops.forEach((stop) => stop.then((unlisten) => unlisten()));
    };
  }, []);

  const clearFinished = useCallback(() => dispatch({ type: "clearFinished" }), []);
  return { transfers, clearFinished };
}

const plural = (count: number) => `${count} ${count === 1 ? "file" : "files"}`;

export function transferSummary(transfers: Transfer[]): string | null {
  const running = transfers.filter((t) => t.status === "running");
  const failed = transfers.filter((t) => t.status === "failed").length;
  const parts: string[] = [];
  if (running.length > 0) {
    const uploads = running.every((t) => t.direction === "upload");
    const downloads = running.every((t) => t.direction === "download");
    const verb = uploads ? "Uploading" : downloads ? "Downloading" : "Transferring";
    const total = running.reduce((sum, t) => sum + t.total, 0);
    const done = running.reduce((sum, t) => sum + t.done, 0);
    const percent = total === 0 ? 0 : Math.floor((done / total) * 100);
    parts.push(`${verb} ${plural(running.length)}`, `${percent}%`);
  }
  if (failed > 0) parts.push(`${failed} failed`);
  return parts.length > 0 ? parts.join(" · ") : null;
}

type StatusBarProps = {
  itemCount: number;
  selectedCount: number;
  selectedBytes: number;
  transfers: Transfer[];
  onOpenTransfers: () => void;
};

export function StatusBar({ itemCount, selectedCount, selectedBytes, transfers, onOpenTransfers }: StatusBarProps) {
  const summary = transferSummary(transfers);
  const running = transfers.filter((t) => t.status === "running");
  const total = running.reduce((sum, t) => sum + t.total, 0);
  const done = running.reduce((sum, t) => sum + t.done, 0);
  return (
    <footer className="statusbar">
      <span>
        {itemCount} {itemCount === 1 ? "item" : "items"}
        {selectedCount > 0 && ` · ${selectedCount} selected · ${formatBytes(selectedBytes)}`}
      </span>
      {summary && (

              <span style={{ transform: `scaleX(${total === 0 ? 0 : done / total})` }} />
            </span>

import { useVirtualizer } from "@tanstack/react-virtual";
import { useEffect, useMemo, useRef, useState, type KeyboardEvent, type MouseEvent } from "react";
import type { Row } from "../hooks/useListing";
import { fileKind, formatBytes, formatModified, type FileKind } from "../lib/format";

export type SortKey = "name" | "size" | "modified";
export type Sort = { key: SortKey; ascending: boolean };

const collator = new Intl.Collator(undefined, { numeric: true, sensitivity: "base" });

function compare(a: Row, b: Row, key: SortKey): number {
  if (key === "size") return (a.size ?? 0) - (b.size ?? 0);
  if (key === "modified") return (a.lastModified ?? "").localeCompare(b.lastModified ?? "");
  return collator.compare(a.name, b.name);
}

export function sortRows(rows: Row[], sort: Sort): Row[] {
  const direction = sort.ascending ? 1 : -1;
  return [...rows].sort((a, b) => {
    if (a.isFolder !== b.isFolder) return a.isFolder ? -1 : 1;
    const byKey = compare(a, b, sort.key) * direction;
    return byKey !== 0 ? byKey : collator.compare(a.name, b.name);
  });
}

export function filterRows(rows: Row[], text: string): Row[] {
  const needle = text.trim().toLowerCase();
  return needle ? rows.filter((row) => row.name.toLowerCase().includes(needle)) : rows;
}

export function nextSelection(
  selected: Set<string>,
  ordered: string[],
  key: string,
  mode: "replace" | "toggle" | "range",
  anchor: string | null,
): Set<string> {
  if (mode === "toggle") {
    const next = new Set(selected);
    if (next.has(key)) next.delete(key);
    else next.add(key);
    return next;
  }
  if (mode === "range" && anchor !== null) {
    const from = ordered.indexOf(anchor);
    const to = ordered.indexOf(key);
    if (from !== -1 && to !== -1) {
      const [start, end] = from < to ? [from, to] : [to, from];
      return new Set(ordered.slice(start, end + 1));
    }
  }
  return new Set([key]);
}

export function FileList(props: FileListProps) {
  const { rows, filter, sort, onSort, selected, onSelectionChange, onOpen, onContextMenu, hasMore, loading, onLoadMore } = props;
  const visible = useMemo(() => sortRows(filterRows(rows, filter), sort), [rows, filter, sort]);
  const ordered = useMemo(() => visible.map((row) => row.key), [visible]);
  const scroller = useRef<HTMLDivElement>(null);
  const anchor = useRef<string | null>(null);
  const [focusIndex, setFocusIndex] = useState(0);

  const virtualizer = useVirtualizer({
    count: visible.length,
    getScrollElement: () => scroller.current,
    estimateSize: () => 28,
    overscan: 12,
    initialRect: { width: 800, height: 600 },
  });
  const items = virtualizer.getVirtualItems();
  const lastIndex = items.length > 0 ? items[items.length - 1].index : -1;

  useEffect(() => {
    if (hasMore && !loading && lastIndex >= visible.length - 20) onLoadMore();
  }, [hasMore, loading, lastIndex, visible.length, onLoadMore]);

  const choose = (key: string, mode: "replace" | "toggle" | "range") => {
    onSelectionChange(nextSelection(selected, ordered, key, mode, anchor.current));
    if (mode !== "range") anchor.current = key;

  const click = (row: Row, index: number, event: MouseEvent) => {

      event.preventDefault();

      setFocusIndex(next);
      virtualizer.scrollToIndex(next);

      event.preventDefault();
      onOpen(visible[focusIndex]);
    } else if (event.key === "a" && event.metaKey) {
      event.preventDefault();
      onSelectionChange(new Set(ordered));
    }
  };

  return (
    <div className="file-list">
      <div className="list-head" role="row">
        {COLUMNS.map((column) => (
          <button
            key={column.key}
            type="button"
            role="columnheader"
            aria-sort={sort.key === column.key ? (sort.ascending ? "ascending" : "descending") : "none"}
            onClick={() => onSort({ key: column.key, ascending: sort.key === column.key ? !sort.ascending : true })}
          >
            {column.label}
            {sort.key === column.key && <span aria-hidden="true">{sort.ascending ? " ▲" : " ▼"}</span>}
          </button>
        ))}
      </div>
      <div
        ref={scroller}
        className="list-scroll"
        role="grid"
        aria-label="Files"
        aria-multiselectable="true"
        tabIndex={0}
        onKeyDown={keyDown}
      >
        <div className="list-canvas" style={{ height: virtualizer.getTotalSize() }}>
          {items.map((item) => {
            const row = visible[item.index];
            const isSelected = selected.has(row.key);
            const kind = fileKind(row.name, row.isFolder);
            return (
              <div
                key={row.key}
                role="row"
                aria-selected={isSelected}
                className={[
                  "file-row",
                  isSelected ? "selected" : "",
                  item.index === focusIndex ? "focused" : "",

                style={{ height: item.size, transform: `translateY(${item.start}px)` }}

                onContextMenu={(event) => {
                  event.preventDefault();

                  if (!isSelected) onSelectionChange(keys);

                </span>
              </div>
            );
          })}

      </div>

  );
}

export function draftFromForm(form: ConnectionForm, id: string | null): ConnectionDraft {
  const override = form.endpoint.trim() || null;
  const account = form.accountId.trim();

    name: form.name.trim(),

    bucket: form.bucket.trim() || null,
    secret: form.secret.trim() || null,
  };

function statusText(t: Transfer): string {
  if (t.status === "failed") return t.error?.message ?? "Failed";
  if (t.status === "finished") return t.direction === "download" ? "Downloaded" : "Uploaded";
  const percent = t.total === 0 ? 0 : Math.floor((t.done / t.total) * 100);
  return `${percent}% · ${formatBytes(t.done)} of ${formatBytes(t.total)}`;
}

function destinationText(t: Transfer): string {
  return t.direction === "download" ? "to Downloads" : `to ${t.destination}`;
}

type TransferDrawerProps = {

  const [open, setOpen] = useState<Record<GroupId, boolean>>({ running: true, failed: true, finished: false });
  const [height, setHeight] = useState(260);

    if (!drag.current) return;

          actions={
            <button type="button" className="button button-primary" onClick={upload}>
              Upload files
            </button>
          }
        />
      );
    }
    return (
      <FileList
        rows={listing.rows}
        filter={filter}
        sort={sort}
        onSort={setSort}
        selected={selected}
        onSelectionChange={setSelected}
        onOpen={openRow}
        onContextMenu={fileMenu}
        hasMore={listing.hasMore}
        loading={listing.loading}
        onLoadMore={listing.loadMore}
      />
    );
  };

  return (
    <div className={noConnections ? "window no-connections" : "window"}>
      <Rail connections={connections ?? []} selectedId={selectedId} onSelect={setSelectedId} onAdd={addConnection} onContextMenu={connectionMenu} />
      {connection && (
        <BucketColumn
          connection={connection}
          buckets={buckets}
          error={bucketsError}
          selected={place?.bucket ?? null}
          onSelect={(bucket) => go({ bucket, prefix: "" })}
        />
      )}
      <main className="main">
        {connectionsError && (
          <EmptyState tone="error" title="Kelp couldn't load your connections" body={connectionsError.message} />
        )}
        {!connectionsError && noConnections && (
          <EmptyState
            image={<img className="empty-logo" src={mark} alt="" width={64} height={64} />}
            title="Welcome to Kelp"
            body="Add a connection to browse your buckets on Amazon S3, Cloudflare R2 or Hetzner."
            actions={
              <>
                <button type="button" className="button button-primary" onClick={addConnection}>
                  Add a connection
                </button>
                <button type="button" className="link-button" onClick={() => api.openDocs("/docs/")}>
                  Where do I find my keys?
                </button>
              </>
            }
          />
        )}
        {!noConnections && connection && !place && (
          <EmptyState
            title="Choose a bucket"
            body={
              connection.lastLocation && buckets && !buckets.includes(connection.lastLocation.bucket)
                ? `The bucket "${connection.lastLocation.bucket}" you had open is gone. Choose another one.`
                : "Pick a bucket on the left to see its files."
            }
          />
        )}
        {connection && place && (
          <>
            <Toolbar
              bucket={place.bucket}
              prefix={place.prefix}
              canBack={position > 0}
              canForward={position < history.length - 1}
              onBack={() => setPosition((p) => p - 1)}
              onForward={() => setPosition((p) => p + 1)}
              onNavigate={(prefix) => go({ bucket: place.bucket, prefix })}
              filter={filter}
              onFilter={setFilter}
              onNewFolder={() => setSheet({ kind: "folder" })}
              onUpload={upload}
            />
            {content()}
            {actionError && (
              <div className="action-error" role="alert">
                <span>{actionError.message}</span>
                <button type="button" className="link-button" onClick={() => setActionError(null)}>
                  Dismiss
                </button>
              </div>
            )}
            {drawerOpen && (
              <TransferDrawer
                transfers={transfers}
                onCancel={(id) => api.cancelTransfer(id).catch((e) => setActionError(toAppError(e)))}
                onReveal={(path) => api.revealInFinder(path).catch((e) => setActionError(toAppError(e)))}
                onClearFinished={clearFinished}
                onClose={() => setDrawerOpen(false)}
              />
            )}
            <StatusBar
              itemCount={listing.rows.length}
              selectedCount={selected.size}
              selectedBytes={selectedBytes}
              transfers={transfers}
              onOpenTransfers={() => setDrawerOpen(true)}
            />
          </>
        )}
      </main>
      {sheet.kind === "connection" && (
        <ConnectionSheet
          initial={sheet.initial}
          onCancel={() => setSheet({ kind: "none" })}
          onSaved={async (profile) => {
            setSheet({ kind: "none" });
            await reloadConnections();
            setSelectedId(profile.id);
            setRefresh((n) => n + 1);
          }}
        />
      )}
      {sheet.kind === "folder" && connection && place && (
        <NewFolderSheet
          onCancel={() => setSheet({ kind: "none" })}
          onCreate={async (name) => {
            await api.createFolder(connection.id, place.bucket, place.prefix, name);
            setSheet({ kind: "none" });
            listing.reload();
          }}
        />
      )}
    </div>
  );
}
```
