# Kelp M4, the rest: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Six drop fixes, Settings and theme, ⌘K palette, quick preview, tabs, and copy/move by dragging rows.

**Architecture:** Each phase is a branch and a PR into `master` (CI must pass); before each PR, a fresh reviewer checks that phase's diff and Important findings are fixed test-first. UI features stay in focused components and hooks; `App` is split so per-tab state lives in a `Browser` component. Copies reuse the M3 queue: a new `Direction::Copy`, new provider calls, and the same pause/resume/retry/restart model.

**Tech Stack:** Rust (tokio, aws-sdk-s3), Tauri 2 (URI scheme protocol, window theme), React 19 + TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-15-kelp-m4-rest-design.md`

## Global Constraints

- No comments in code; no `unwrap`/`expect` outside tests; no std lock held across `.await`.
- `cargo fmt`, `cargo clippy --all-targets -D warnings`, `cargo test`, `npm test`, `npm run typecheck`, `npm run build` pass at every commit (CI enforces it on each PR).
- No new npm or Rust dependencies. One new capability only: `core:window:allow-set-theme`. CSP adds `kelp-preview:` to `img-src`, `media-src`, `connect-src` and nothing else.
- No presigned URLs, secrets, bucket names or keys in logs or errors beyond what M3 already shows.
- Semantic CSS tokens only; every animation off under `prefers-reduced-motion`; visible focus states.
- Deleting (move) and overwriting always confirm in the UI.
- Copy is exact as written in the spec. Sentence case; buttons say what they do.
- Commits: author ozan8@hotmail.co.uk, plain messages, no `Co-Authored-By`. One branch per phase, named below.

## Review Focus

1. **Moving a folder into itself or its own subfolder:** refused before anything is copied or deleted. Test in Task 7.1.
2. **A move whose delete fails:** the copy stays, the item fails with the provider's message, nothing else is deleted. Test in Task 6.3.
3. **Keyboard shortcuts while typing** (filter field, sheet inputs, palette field): never trigger actions. Test in Task 3.2.
4. **Preview of a key with spaces, `#`, `?` or unicode:** the `kelp-preview` URL round-trips the exact key. Test in Task 4.1.
5. **`transfers.json` from M3 (no copy fields):** still loads and resumes. Test in Task 6.1.
